# هزینه و وابستگی‌های جدید مأموریت v2

- وابستگی npm جدید: **هیچ** (`pdfjs-dist` از مأموریت قبلی، devDep، رایگان MIT، فقط Runner Node خارجی).
- سرویس پولی: **صفر**. OCR/LLM خاموش (Provider دستی طبق ADR-005). Queue جدید: صفر (Job/Lease روی DB موجود).
- ZIP: پیاده‌سازی داخلی ~۶۰ خط (روش STORE + CRC32) — بدون کتابخانه خارجی.
- هزینهٔ اجرا: فقط ردیف‌های تازهٔ DB (`telegram_updates`، `telegram_reply_effects`، `feedback_*`، `books*`، mappings) — ناچیز در مقیاس پایلوت.
- ریسک هزینه: ارسال تلگرام برای Reply پشتیبانی — محدود به پاسخ‌های Inbox، بدون ارسال انبوه (طبق سند ۱۲٫۶).
- Retention: پیام‌های خام فیدبک و Outbox هنوز سیاست حذف خودکار ندارند → اقدام HUMAN (سیاست محصول).
