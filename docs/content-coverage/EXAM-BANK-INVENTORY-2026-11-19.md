## ۲. کدام سال‌ها را اصلاً نداریم

- **هیچ سالی کامل نیست.** هیچ سالی در بانک سؤال، حتی یک دفترچهٔ کامل ندارد.
- **دفترچهٔ ثبت‌شده صفر است.** در `YEARLY_KONKOR_BOOKLETS` پانزده دفترچهٔ ارشد ثبت شده، اما سؤال‌های موجود در آن‌ها نمونه‌های پراکنده‌اند؛ سؤال ۲۸۵ از ۲۸۵ در هیچ سالی وجود ندارد.
- **دکتری ساختار ثبت‌شده ندارد.** هیچ دفترچهٔ ۲۱۶۲ در بانک ثبت نشده است. ۱۲۲ سؤال دکتری موجود، فقط بخش زبان انگلیسی ۱۴۰۳ تا ۱۴۰۵ و یک سؤال از هر سال قدیمی‌تر است. بخش تخصصی دکتری و درس‌های تخصصی آن هیچ سؤالی ندارد.
- **سال‌های کم‌سؤال بیشتر مشخص است:** ۱۳۹۷، ۱۳۹۸، ۱۳۹۹ و ۱۴۰۱ هر یک چهار سؤال؛ ۱۳۹۶ و ۱۴۰۴ پنج سؤال؛ ۱۳۹۳، ۱۳۹۴ و ۱۳۹۵ پنج تا شش سؤال.

## ۳. چرا این شکاف با OCR پر نمی‌شود

منبع متن این آزمون‌ها چهار چیز است: خروجی MinerU از PDF دفترچه‌ها (۱۳۹۱ تا ۱۴۰۵)، OCR docx (۱۳۹۶ تا ۱۴۰۵ برای هر دو سطح)، فایل‌های کلید تبدیل‌شده، و کارنامه‌های طبقه‌بندی‌شده در `content/exam-import-staging`.

خود PDF دفترچه‌ها در مخزن نیستند و نسخه‌هایی که از اینترنت گرفته شد هم تصویری‌اند، یعنی لایهٔ متن ندارند و هر بار باید OCR شوند. برای سنجش کیفیت، مولد تازه‌ای نوشته شد (`scripts/import-exam-persian.mts`) که ۱۴۰۲، ۱۴۰۳ و ۱۴۰۴ را از منبع MinerU می‌خواند؛ نتیجه:

| مرحله | تعداد |
| --- | --- |
| نامزد خام (گروه چهارگزینه‌ای شناسایی‌شده) | ۶۱۵ |
| گذر از دروازهٔ ساختاری (صورت سؤال سالم، چهار گزینهٔ یکتا) | ۳۸۶ |
| گذر از دروازهٔ واژگانی (کمتر از ۸٪ واژهٔ ناشناس) | ۱۹۳ |
| گذر از دروازهٔ شماره و کلید (شمارهٔ خالی در بازه و کلید رسمی موجود) | ۱۷۱ |

نمونه‌ای از متن بازمانده: «جیران مافات» به‌جای «جبران مافات»، «تشبیت» به‌جای «تثبیت»، «شهریدی» به‌جای «شهودی»، «نزاد صالحان» به‌جای «نزد صالحان». یعنی در هر هفت واژه حدود یک واژه معیوب است. چنین متنی سؤال را ناخوانا می‌کند و در بانکی که دانش‌آموز از آن آزمون می‌دهد، بدتر از نبودن سؤال است.

به همین دلیل نامزدهای سالم‌تر در `content/exam-import-staging/ocr-persian/` نگه داشته می‌شوند و به `src/data` نمی‌روند. این خروجی با `npm run import:exam-persian -- --write` بازتولید می‌شود.

## ۴. کلید پاسخ

شاهد کلید ۳۰۶۹ مدخل برای ۱۳۹۰ تا ۱۴۰۴ دارد و در `content/exam-key-evidence/answers-by-year.json` است. سه کمبود شناخته‌شده:

- کلید ۱۴۰۵ بازیابی نشده است. فایلی که پیدا شد سربرگ ۱۱۵۲ دارد و به دفترچهٔ ۳۱۹A نمی‌خورد.
- ۱۴۰۰ برابر ۲۳۶ از ۲۹۵ و ۱۴۰۲ برابر ۲۷۰ از ۲۸۵ و ۱۴۰۴ برابر ۲۹۳ از ۲۸۵ حفره دارند.
- هشت سال فقط کلید اولیه دارند که سنجش خودش آن را غیرقابل استناد می‌خواند.

کلید دکتری ۲۱۶۲ در مخزن هیچ سندی ندارد.

## ۵. کاری که شکاف را واقعاً می‌بندد

سه مسیر هست و هر سه به یک چیز نیاز دارند: متن تمیز.

۱. **متن دیجیتال رسمی.** اگر نسخهٔ متنی دفترچه‌های ۱۱۴۲ و ۲۱۶۲ (PDF با لایهٔ متن یا Word) به دست بیاید، همان مولد با دروازه‌های موجود همهٔ ۴۴۸۰ سؤال را می‌آورد. هیچ بخشی از کار دوباره نوشته نمی‌شود.
۲. **رونویسی دستی هدایت‌شده.** برای هر سال، سؤال‌ها از تصویر خوانده و در قالب ساده‌ای نوشته می‌شوند؛ مولد موجود سپس شماره، درس، گزینه‌ها و کلید را از شاهد رسمی پر می‌کند.
۳. **بهبود OCR فارسی.** اگر مدل دقیق‌تری در دسترس باشد، همان مسیر بخش ۳ نتیجهٔ بهتری می‌دهد، ولی تا امروز هیچ خروجی OCR فارسی این مجموعه به کیفیت قابل انتشار نرسیده است.

## ۶. دستورها

```bash
npm run exam:inventory         # همین جدول را از داده‌های فعلی می‌سازد
npm run audit:exam-bank        # ساختار، کلید و پوشش هر سال
npm run import:exam-persian    # گزارش نامزدهای فارسی از OCR
npm run evidence:exam-keys     # بازتولید شاهد کلید رسمی
```
