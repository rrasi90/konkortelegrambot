## ۲. پوشش دکتری (کد ۲۱۶۲)

۱۲۳ سؤال با برچسب دکتری در بانک سالی ثبت است: ۳۳ سؤال ۱۴۰۳، ۴۱ سؤال ۱۴۰۴، ۴۰ سؤال ۱۴۰۵ و یک سؤال برای هر سال ۱۳۹۴ تا ۱۴۰۲. هیچ دفترچهٔ رسمی دکتری در سامانه ثبت نشده است، پس مخرج کسر وجود ندارد و درصد پوشش قابل محاسبه نیست.

## ۳. وضعیت کلید پاسخ

شاهد کلید رسمی ارشد برای سال‌های ۱۳۹۰ تا ۱۴۰۴ در `content/exam-key-evidence/answers-by-year.json` نگه داشته می‌شود. این شاهد از تلاقی لایهٔ متن PDF و OCR ساخته شده است و حفره دارد: ۱۴۰۰ برابر ۲۳۶ از ۲۸۴، ۱۴۰۲ برابر ۲۷۰ از ۲۸۵ و ۱۴۰۴ برابر ۲۹۳ از ۳۹۹. کلید ۱۴۰۵ بازیابی نشده است.

شش اختلاف شناخته‌شده در `content/exam-key-evidence/known-key-conflicts.json` ثبت شده‌اند. داوری محتوایی چهار مورد را به نفع بانک می‌داند (کشش قیمتی ۱۳۹۶ سؤال ۹۹، شاخص خالص مروجان ۱۴۰۳ سؤال ۱۸۶، بوروکراسی ماشینی ۱۳۹۳ سؤال ۶۹ و کارت امتیازی متوازن ۱۳۹۸ سؤال ۸۳). دو مورد باقی‌مانده (۱۳۹۶ سؤال ۳۸ و ۱۳۹۹ سؤال ۱۹۸) تا مشاهدهٔ تصویر کلید رسمی باز است.

## ۴. چه چیزی در این تغییر اصلاح شد

- شاهد کلید رسمی وارد مخزن شد تا بازبینی در محیط تازه و در CI هم تکرارپذیر باشد.
- دستور `npm run audit:exam-bank` اضافه شد و در CI اجرا می‌شود. این دستور ساختار بانک، پوشش هر سال و تطبیق کلید بانک با شاهد رسمی را می‌سنجد و روی اختلاف ثبت‌نشده قرمز می‌شود.
- تست نگهبان `src/tests/examBankIntegrity.test.ts` اضافه شد: سؤال بدون کلید، گزینهٔ ناقص، شمارهٔ تکراری، شمارهٔ بیرون از بازهٔ دفترچه و متن تکراری را می‌گیرد.
- ۱۹ سؤال بخش انگلیسی ارشد ۱۴۰۲ و ۱۴۰۳ از متن دفترچه وارد شد. ورود خودکار فقط برای بخش انگلیسی مجاز است، چون متن لاتین خطای OCR قابل‌تشخیص دارد و کلید رسمی هر شماره در شاهد موجود است.
- بازتولید رجیستری کلید امن شد. بانک‌های `src/data` پس از R-036 دیگر فیلد کلید ندارند، پس بازتولید ساده کلیدهای تاریخی را پاک می‌کرد؛ اکنون رجیستری موجود پایهٔ کار است و کلید سؤال‌های تازه از فایل سمت سرور اضافه می‌شود.

## ۵. چه چیزی مانده است

۱. **رونویسی ۲۷۶ سؤال ۱۴۰۵.** بستهٔ بازبینی ۱۴۰۵ در `content/exam-import-staging/management-1142-2162-20261115/manual-review` نوشته است که متن و چهار گزینهٔ ۹۵ سؤال رونویسی شده و ۱۹۰ سؤال دیگر رونویسی نشده است. پروندهٔ حقوقی همین بسته می‌گوید تکثیر و انتشار سؤال‌ها حتی پس از آزمون فقط با مجوز سازمان سنجش مجاز است و `rightsStatus` این منبع «restricted» و `allowedUse` خالی است. تا روشن‌شدن مجوز، ورود انبوه کار درستی نیست.

۲. **کلید رسمی ۱۴۰۵ و کلید دکتری.** برای ۱۴۰۵ فقط یک فایل محلی با سربرگ ۱۱۵۲ و کد کنترل ۱۱۷A پیدا شده که نامنطبق است و رد شد. لینک دقیق سنجش برای ۱۱۴۲ و ۳۱۹A شناسایی شده اما دریافت فایل زمان تمام می‌کند. برای کد ۲۱۶۲ در مخزن هیچ سند کلیدی ثبت نشده است.

۳. **متن فارسی دفترچه‌ها.** متن استخراج‌شدهٔ MinerU برای بخش‌های فارسی شمارهٔ سؤال و گزینه‌ها را در هم می‌ریزد. در آزمون خودکار تنها بخش انگلیسی به‌طور قابل‌اتکا قابل استخراج بود و بقیه رد شد. ورود خودکار بخش فارسی پیش از بازبینی صفحه‌به‌صفحه، متن شکسته به بانک اضافه می‌کند.

۴. **شمارهٔ سؤال‌های تألیفی.** سؤال‌هایی مثل `q.phd1404.211` شمارهٔ ۲۱۱ دارند. جلد دفترچهٔ ۱۴۰۴ کد ۲۱۶۲ نشان می‌دهد آن دفترچه ۳۲۰ سؤال در هشت بستهٔ ۴۰ سؤالی دارد، پس چنین شماره‌ای در دفترچه وجود دارد. با این حال این سؤال‌ها تألیفی‌اند و باید در گام بعد به‌عنوان تألیفی برچسب بگیرند تا با سؤال رسمی اشتباه نشوند.

## ۶. دستورهای بازبینی

```bash
npm run audit:exam-bank       # پوشش، ساختار و تطبیق کلید
npm test                      # تست نگهبان بانک سؤال
npm run evidence:exam-keys    # بازتولید شاهد کلید از خروجی بازیابی محلی
npm run import:exam-markdown  # ورود دوبارهٔ سؤال‌های انگلیسی از متن دفترچه
```
