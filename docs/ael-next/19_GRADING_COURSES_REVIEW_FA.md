# EX-06 / LEARN-02 / LEARN-04 — تصحیح تشریحی، خط تولید درس و سیاست مرور

- **تاریخ:** ۵ نوامبر ۲۰۲۶ / ۱۴ آبان ۱۴۰۵

## ۱. EX-06 — قرارداد تصحیح انسانی تشریحی

- **کد:** `recordEssayEvaluation` در `packages/learning-engine/src/formative-quiz.ts` (۶ تست).
- **قرارداد:** تشریحی تا تصحیح انسانی وضعیت `pending` دارد و **هرگز** خودکار درست/غلط یا نمرهٔ نهایی نمی‌گیرد (AT-17). تصحیح: `graderId` + `verdict (acceptable|needs_review)` + `score? (۰–۱۰۰)` + `gradedAt` + `version` → `status: evaluated`. نتیجهٔ قبلی و تاریخچهٔ مصحح حفظ می‌شود (AT-18).
- **نمرهٔ موقت:** کارنامه تعداد «در انتظار» را جدا نشان می‌دهد (بخش ۱۵٫۵ نقشه راه)؛ درصد قطعی فقط با مخرج «سؤال‌های قابل تصحیح» محاسبه می‌شود.
- **باز:** نقش/مجوز مصحح و صف تصحیح در ADMIN-01 (زیر) — تابع فعلی قرارداد ثبت است و رابط تصحیح انسانی ندارد.

## ۲. LEARN-02 — خط تولید بستهٔ درس

مکانیک موجود و ژنریک است (بدون صفحهٔ اختصاصی — AT-30):

1. بستهٔ JSON طبق قرارداد سند ۰۴ (ساختار مالی/آمار را الگو بگیر؛ شناسه‌های موجود را دست نزن).
2. `origin: authored` / `rights: original_ael` / `review: pending_sme` — اعتبارسنج مقدار دیگری نمی‌پذیرد.
3. ثبت یک‌خطی در `apps/worker/src/learning-catalog.ts` (آداپتور آفلاین و سرور از همین رجیستری می‌خوانند).
4. کنترل‌ها: `npm run validate:learning` → `npm test` → `npm run build:offline` → `npm run audit:miniapp`.
5. ثبت گزارش (نام درس، نسخه، تعداد، وضعیت منابع) در BACKLOG و ارجاع به بازبینی SRC-04.

**تأیید متخصص همچنان Gate انتشار است؛ افزودن به رجیستری = «آزمایشی»، نه «منتشرشده».**

## ۳. LEARN-04 — سیاست مرور و همزیستی با FSRS

- **مسیر تألیفی (فعلی، ساده):** غلط/نزده → ۱ روز؛ نخستین پاسخ درست → ۳ روز؛ streak ≥ ۲ → ۷ روز. سقف روزانه و تعویق اختیاری کاربر؛ وقفه جریمه ندارد (R-14). الگوریتم نسخه‌دار است و تغییرش با نسخه و تست مهاجرت.
- **مسیر FSRS (موتور اصلی):** جداست و ادغام نمی‌شود مگر با طرح مهاجرت: تعریف مالکیت داده، معنای رتبه‌ها، پشتیبان تاریخچه، اجرای موازی با پرچم، مقایسهٔ بار مرور، سپس سوئیچ نسخه‌دار. **هیچ ادعای برتری FSRS در AEL بدون سنجش (بخش ۱۲٫۳) ثبت نمی‌شود.**
- کاربر بتواند خاموش کند: پیش‌فرض سیاست در نمای مرور قابل مشاهده و قابل رد است.

## ۴. LEARN-03 — موتور پیشنهاد (پیاده‌سازی این بسته)

`recommendNextActivity` در موتور: ترتیب غلط دارای مقصد ← موعددار ← خوانده‌نشدهٔ آماده؛ بودجهٔ ۵/۱۰/۲۰ دقیقه؛ حالت «اطلاعات ناکافی»؛ هر پیشنهاد با دلیل و قابل رد. اتصال به خانهٔ مینی‌اپ کار UX بعدی است.
