# شواهد راستی‌آزمایی نسخهٔ جدید

| بررسی | نتیجه |
|---|---|
| Vitest کل پروژه | ۳۶۷ تست در ۲۸ فایل موفق |
| مرورگر Mini App قبلی | ۲۰ بررسی موفق |
| مرورگر مسیر جدید Mini App | ۷ بررسی موفق، با Worker محلی و احراز هویت آزمایشی |
| مرورگر فایل HTML | ۸ بررسی موفق، با مسیر فایل مستقیم و HTTP/HTTPS مسدود |
| تأیید محتوای جدید | ۸ درس، ۲۴ سؤال تألیفی، ۸ ارجاع مفهومی و دو الگوی تاریخی قابل بازتولید |

| کنترل منفی اسکن | فایل آفلاین عمداً با ۲۴ فیلد کلید پاسخ برای انتشار عمومی رد شد |
| Wrangler | Dry Run موفق |
| دیتابیس | اجرای تازه، replay مبتنی بر ledger، کنترل تغییر داده و پشتیبان/بازیابی در دیتابیس موقت موفق |

شواهد اجرا و تصاویر آزمایشی در `handoff/verification/` قرار دارند. محیط تست واقعی Telegram و بررسی انسانی محتوای تألیفی و شواهد ده‌ساله در این اجرای محلی تأیید نشده‌اند. شاخص‌های بهبود سرعت و یادگیری به پایلوت داوطلبان وابسته‌اند.
