# شواهد راستی‌آزمایی نسخهٔ جدید

**به‌روزرسانی: ۵ نوامبر ۲۰۲۶ (بستهٔ GOV-01/QA-01).** این سند پس از اجرای تمیز با `npm ci` در همان روز دوباره تأیید شد. سند مرجع وضعیت فعلی [10_EXECUTION_STATUS_FA.md](10_EXECUTION_STATUS_FA.md) است. اصلاحات نسبت به نسخهٔ قبلی: شمار تست‌ها، محدودهٔ محتوا و برچسب الگوهای تاریخی با دادهٔ فعلی تطبیق داده شد.

| بررسی | نتیجه |
|---|---|
| نصب تمیز | `npm ci` از lockfile نسخهٔ ۳ با Node v24.18.0 و npm 12.0.1 موفق (اجرای ۵ نوامبر ۲۰۲۶) |
| Vitest کل پروژه | ۳۸۳ تست در ۲۸ فایل موفق |
| TypeScript و ساخت Worker | موفق (`tsc --noEmit`) |
| اعتبارسنجی محتوای یادگیری | `validate:learning` موفق: ۸ مبحث و ۲۴ سؤال مالی + ۲ مبحث و ۵ سؤال آمار (شامل ۱ تشریحی)، ۱۰ منبع، ممیزی ۵ شاهد |
| شواهد تاریخی | یک الگوی کاندید (`strategy.bcg.quadrants`، سال‌های ۱۴۰۲ و ۱۴۰۵) با وضعیت `trace_pending_review`؛ دو رکورد کشش تقاضا به‌دلیل تعارض گزینه/علامت با بانک از استخراج کنار گذاشته شدند |
| مرورگر Mini App قبلی | ۲۰ بررسی موفق |
| مرورگر مسیر جدید Mini App | ۷ بررسی موفق، با Worker محلی و احراز هویت آزمایشی |
| مرورگر فایل HTML | ۸ بررسی موفق، با مسیر فایل مستقیم و HTTP/HTTPS مسدود |
| اسکن Assetهای Mini App و خروجی عمومی | موفق (`audit:miniapp`: بدون کلید جاسازی‌شده) |
| کنترل منفی اسکن | فایل آفلاین عمداً با ۲۴ فیلد کلید پاسخ برای انتشار عمومی رد شد |
| دیتابیس | `test:db` موفق: اجرای تازهٔ ۱۸ مهاجرت، replay مبتنی بر ledger، کنترل تغییر داده، تست‌های یکپارچگی ارسال آزمون و پشتیبان/بازیابی در دیتابیس موقت |
| اشکال ثبت‌شده و رفع‌شده | چک‌های تازگی `--check` در `extract-learning-recurrence.mjs` و `build-question-index.mjs` با `core.autocrlf=true` ویندوز به‌دلیل اختلاف CRLF/LF غلط شکست می‌خوردند؛ مقایسه پس از نرمال‌سازی EOL اصلاح شد (محتوا بدون تغییر) |

یادداشت نسخهٔ قبلی (منسوخ): «۳۶۷ تست»، «۲۴ سؤال تألیفی» و «دو الگوی تاریخی» دیگر معتبر نیستند؛ اعداد و وضعیت فعلی در جدول بالا و در سند ۱۰ ثبت شده است.

شواهد اجرا و تصاویر آزمایشی در `handoff/verification/` قرار دارند. محیط تست واقعی Telegram و بررسی انسانی محتوای تألیفی و شواهد ده‌ساله در این اجرای محلی تأیید نشده‌اند. شاخص‌های بهبود سرعت و یادگیری به پایلوت داوطلبان وابسته‌اند.
