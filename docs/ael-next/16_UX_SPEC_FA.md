# UX-01/02/03 — نقشهٔ جریان و قرارداد صفحه‌ها

- **تاریخ:** ۵ نوامبر ۲۰۲۶ / ۱۴ آبان ۱۴۰۵
- **مبنا:** بخش ۳ و ۵ نقشهٔ راه. شخصیت‌ها فرض طراحی‌اند و باید با مشاهدهٔ کاربر واقعی اصلاح شوند (QA-03).

## ۱. نقشهٔ جریان

```
خانه ── «ادامه» (بازکردن آخرین نشست) · «تمرین کوتاه» (۵ سؤال) · «مرور»
  │
  ├─ مطالعه: درس ← مبحث (جست‌وجوی فارسی + فیلتر مرجع) ← بند (نکته/فرمول/مثال/دام)
  │            نشانک و آخرین بند جدا از «مطالعه شد» · بازگشت به نقطهٔ قبل
  ├─ آزمون: «تمرین سریع» · «ساخت آزمون» (درس/مبحث/سهمیه/تعداد) · «زمان‌دار»
  │            پیش‌نمایش ظرفیت (EX-01) ← شروع با نسخهٔ pin (AT-12)
  └─ مرور: غلط‌ها · نزده‌ها · نشان‌ها · موعددار (۱/۳/۷ روز)
```

هر صفحه یک اقدام اصلی دارد؛ تنظیمات پیشرفته بازشونده‌اند. «مطالعه کردم» ≠ «تمرین کردم» ≠ «شواهد تسلط».

## ۲. جزئیات سؤال (قرارداد، پیاده‌سازی‌شده در learning.js)

- **قبل از پاسخ:** صورت، مبحث، سطح، برچسب «تألیفی · در انتظار بازبینی متخصص»، زمان‌سنج در حالت زمان‌دار. کلید و تحلیل قبل از ثبت ارسال/نمایش نمی‌شود (AT-13).
- **بعد از پاسخ مجاز:** درست/غلط/نزده، پاسخ درست، حل، **تحلیل تک‌تک گزینه‌ها** (optionReasons)، شناسه + نسخهٔ بسته، وضعیت بازبینی، منابع، نشان، گزارش ایراد.
- **خطا ← مطالعه:** دکمهٔ «مطالعهٔ بخش مرتبط» (readingBlock) با بازگشت به همان پاسخ (`lessonReturn`)؛ بدون مقصد → مبحث مرتبط؛ بدون هیچ مقصد → فهرست درس. علت روان‌شناختی حدس زده نمی‌شود (AT-21/AT-22).
- **تمرین انتقالی (جدید در این بسته):** دکمهٔ «تمرین هم‌مفهوم با سؤال تازه» پس از غلط — جلسهٔ تمرینی ۱ سؤالی از همان مبحث، خارج از گروه هم‌ارزی سؤال جاری، با seed بازتولیدپذیر. اگر نمونهٔ مستقلی نیست، پیام صادقانه «سؤال مستقل دیگری نیست» می‌آید (بخش ۱۵٫۳؛ هیچ نمونه‌ای تأییدشده جلوه داده نمی‌شود).

## ۳. اتصال‌های فنی این بسته

| لایه | تغییر |
|---|---|
| موتور | `findTransferQuestion(course, questionId)` در `packages/learning-engine/src/formative-quiz.ts` — سؤال مستقل هم‌مبحث خارج از گروه هم‌ارز؛ null = نمونه نیست |
| سرور | `POST /api/learning-quiz/transfer` → `startTransferQuiz` در `apps/worker/src/learning-paths.ts` (نشست امضاشدهٔ تمرینی ۱ سؤالی) |
| آفلاین | `api.transfer` در `tools/offline/adapter.ts` با همان قرارداد |
| UI | `beginTransfer()` + دکمه در نمای نتیجهٔ `apps/miniapp/learning.js` |
