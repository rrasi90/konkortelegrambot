# آزمون مستقیم HTML آفلاین و ثبت ایراد

`tools/offline/AEL_OFFLINE.html` را در Chrome، Edge یا Firefox باز کنید. نصب بسته، سرور و ورود تلگرام لازم نیست. استفاده از یک فایل ثابت به مرورگر اجازه می‌دهد نشست را در همان دستگاه بازیابی کند. بعضی تنظیمات مرورگر، ذخیرهٔ فایل محلی را محدود می‌کنند.

| آزمون دستی | کار | نتیجهٔ مورد انتظار |
|---|---|---|
| Q01 | اینترنت را قطع و HTML را مستقیم باز کن | عنوان و مسیر مدیریت مالی ظاهر شوند. |
| Q02 | در نمایش باریک موبایل مسیر را باز کن | اسکرول افقی نداشته باشد. متن فارسی، عدد و فرمول خوانا باشند. |
| Q03 | درس پیشنهادی و ارجاع را باز کن | هدف، مثال، دام، فصل و نشانی متنی منبع دیده شوند. |
| Q04 | تمرین را شروع و گزینه را فقط انتخاب کن | پاسخ‌نامه پنهان بماند تا دکمهٔ ثبت زده شود. |
| Q05 | پاسخ ثبت کن و تحلیل را باز کن | پاسخ صحیح، حل، چهار دلیل گزینه، شناسه، نسخه و وضعیت بازبینی دیده شود. |
| Q06 | سؤال را نشان بزن، ایراد ثبت کن و صفحه را ببند یا بازخوانی کن | نشست قبلی و نتیجه در همان مرورگر قابل ادامه باشند. |
| Q07 | زمان‌دار را باز کن، سؤال را علامت بزن و به سؤال بعد برو | علامت و انتخاب قبلی حفظ شوند و کلید پنهان بماند. |
| Q08 | یک سؤال را پاسخ نده و آزمون را نهایی کن | تعداد نزده جدا گزارش شود و کارنامه هر سؤال جزئیات داشته باشد. |
| Q09 | صفحهٔ الگوهای ده دوره را باز کن | دو الگوی ردیابی‌شده و سال، کد و شماره در جزئیات دیده شوند. |
| Q10 | در صفحهٔ گزارش ایراد خروجی JSON بگیر | شناسهٔ سؤال، شرح و زمان در فایل باشند. اطلاعات شخصی را در شرح وارد نکن. |

برای ثبت ایراد بهتر است انتظار، رفتار دیده‌شده، مسیر کلیک، اندازهٔ صفحه و شناسهٔ سؤال را بنویسی. متن خطا و نمونهٔ کوتاه کافی‌اند.

برای نگهداری پیشرفت، از صفحهٔ اصلی «پشتیبان‌گیری و بازیابی» را باز کن و فایل JSON را ذخیره کن. برای بازیابی همان فایل را انتخاب و جایگزینی وضعیت جاری را تأیید کن. نسخهٔ درس و شناسهٔ سؤال‌ها هنگام بازیابی بررسی می‌شوند و متن و پاسخ‌ها از بستهٔ محلی بازسازی می‌شوند. زمان پایان آزمون زمان‌دار بعد از بازیابی تغییر نمی‌کند. فایل ناقص یا ناسازگار وضعیت فعلی را جایگزین نمی‌کند.

## بازتولید و آزمون

```sh
npm ci
npm run validate:learning
npm run build:offline
npm run audit:miniapp
CHROME_PATH=/path/to/chromium node scripts/e2e-learning-ui.mjs offline
```

برای آزمون مرورگری Mini App ابتدا `npm run dev:miniapp` را در ترمینال دیگر اجرا کنید. سپس همان اسکریپت را با آرگومان `miniapp` اجرا کنید. آزمون آفلاین مسیر `file://` را باز می‌کند و HTTP/HTTPS را مسدود می‌کند. HTML آفلاین پاسخ‌های تمرین تألیفی را در خودش دارد و نباید در پوشهٔ انتشار عمومی قرار بگیرد.
