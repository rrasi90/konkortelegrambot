# الحاقیهٔ اصلاحی گزارش مأموریت v4 — versioned (مأموریت v5 §3)

تاریخ: ۲۰۲۶-۱۱-۱۱ · نویسنده: مأموریت v5 (اصلاح شواهد) · گزارش مادر: `MISSION_V4_FINAL_REPORT.md` (سند تاریخی — متن آن تغییر نکرده است)

## چرا این الحاقیه؟

گزارش v4 شمارش‌های Ledger و Gap Register را با regex/split غیرقابل‌اعتماد استخراج کرده بود و
اعداد آن با واقعیِ CSV نمی‌خواند. این الحاقیه اعداد صحیح را با parser استاندارد
(`scripts/ledger-gap-reconcile.mts`، تست: `src/tests/v3/ledger-gap-register.test.ts`) ثبت می‌کند.
سابقهٔ گزارش v4 عمداً حفظ شده است.

| شاخص | گزارش v4 (نادرست) | واقعی (parser معتبر) |
|---|---|---|
| DONE (کل شامل FX/HD) | ۲۴ | **۲۳** = V3:۱۰ + FX:۵ + HD:۸ |
| DONE_WITH_DEFAULT | ۳ | **۳** (همهٔ V3-020/021/061) |
| NOT_STARTED (V3) | ۱۳ | **۱۵** (022..027، 030..033، **040..044**) |
| PARTIAL (V3) | ۴ | **۴** (052/053/070/071) |

- خطای اصلی گزارش v4: در شمارش DONE، ردیف‌های FX/HD را با V3 مخلوط کرد و دو NOT_STARTED (از 040..044) را جا انداخت.
- **V3-040 در فهرست «باقیمانده‌های واقعی» گزارش v4 غایب بود** — این الحاقیه آن را به‌عنوان تسک باز اولویت‌دار (پیش‌نیاز V3-041..044) ثبت می‌کند.

## ۲. اصلاح شمارش Gap Register (§3.2)

| شاخص | گزارش v4 (نادرست) | واقعی |

  منتقل شد — بدون از بین رفتن شواهد قبلی (تست enforce می‌کند).
