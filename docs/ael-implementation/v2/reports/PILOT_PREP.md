# آماده‌سازی پایلوت محدود (QA-03/V2-111) — مسیر دکتری مدیریت

- تصمیم مالک: آماده‌سازی پایلوت محدود دکتری؛ اجرای واقعی فقط پس از معیارهای فنی/محتوایی.
- شرکت‌کننده/تاریخ: هنوز تعیین نشده (NOT_YET_SCHEDULED). نام/تاریخ/نتیجهٔ واقعی جعل نشد.

## سناریوها (پوشش کامل چرخه)

1. ورود/Onboarding: انتخاب هدف دکتری مدیریت، سال/ترکیب، زمان مطالعه.
2. تعیین سطح (diagnostic): شروع از UNKNOWN، بدون پیش‌فرض تسلط.
3. مطالعه: درسنامه + مثال + نکته؛ آموزش زیر هر سؤال (طبق قرارداد).
4. مرور: FSRS + کارت‌های موعددار؛ تکرار فاصله‌دار.
5. پاسخ اشتباه: خطای ← مطالعه (readingBlock) + تمرین انتقالی.
6. پایان جلسه: گزارش صادقانه بدون رتبه/تراز (FORBIDDEN_PHRASES).
7. بازگشت کاربر: CloudStorage snapshot بازیابی + هشدار device-only در صورت نبود CloudStorage.

## معیار موفقیت (انتظار/قابل‌مقایسه)

- هدف فنی: 0 خطای کنسول در جلسات داخلی؛ p99 همان‌خروجی vs-5 در سناریوهای داخلی.
- هدف محتوایی: هر سؤال دارای explanation + tap ولی SME پس از REV-01.

## داده‌های موردنیاز ثبت

- learner_id (پایدار)، skill_id، پاسخ‌ها + زمان، FSRS retrievability، proof/holdout.

## قالب اشکال
