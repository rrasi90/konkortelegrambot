# تصمیم‌های نیازمند تأیید مالک

این فایل حاوی تمام مواردی است که نیاز به تصمیم، تأیید یا امضای انسان (مالک یا متخصص) دارند. ایجنت این فایل را فقط می‌خواند و هرگز تغییر نمی‌دهد.

### D-05 — ادغام شاخه‌ها
- پرسش دقیق: کدام استراتژی ادغام برای ادغام شاخه‌های موجود به کار گرفته شود؟
- گزینه‌ها: الف — ادغام ترتیبی با PR جداگانه | ب — ساخت شاخه یکپارچه از پایهٔ علمی | پ — آرشیو شاخه‌های رها‌شده
- پیش‌فرض موقتی که اعمال کردم: الف، با شرط CI سبز
- چه چیزی را باز می‌کند: کارهای V2-03A تا V2-03C
- پاسخ لازم از مالک: «الف» یا «ب» یا «پ»
