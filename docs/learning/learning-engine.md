# قواعد موتور یادگیری

مرجع پیاده‌سازی: [`packages/learning-engine/src/index.ts`](../../packages/learning-engine/src/index.ts) — تمام قواعد این سند آنجا به‌صورت تابع خالص پیاده شده و با تست واحد پوشش داده شده‌اند.

## پارامترها (قابل تنظیم در `EngineConfig`)

| پارامتر | مقدار پیش‌فرض | نقش |
|---|---|---|
| `masteryGain` | ۰٫۱۵ | سهم رشد تسلط پس از پاسخ درست |
| `masteryPenalty` | ۰٫۷۵ | ضریب کسر تسلط پس از پاسخ غلط |
| `linkedPenalty` | ۰٫۲۵ | ضریب اثر خطا بر گرهٔ وابسته |
| `rippleThreshold` | ۶۰ | آستانهٔ فعال‌سازی لایهٔ ۲ |
| `siblingIntervalFactor` | ۰٫۵ | ضریب نصف‌کردن فاصلهٔ هم‌خانواده‌ها |
| `easePenalty` | ۰٫۲۰ | کاهش سهولت کارت پس از خطا |
| `easeMin` / `easeMax` | ۱٫۳ / ۲٫۸ | مرز سهولت |
| `rippleCapacity` | ۶ | سقف کارت‌هایی که موج به برنامهٔ فردا اضافه می‌کند |

## فرمول‌های تسلط

پاسخ درست (رشد میرا، هرچه تسلط بیشتر رشد کمتر):

```
M_new = M_old + (100 − M_old) × 0.15
```

پاسخ غلط (سقوط شدیدتر — ۲۵٪):

```
M_new = M_old × 0.75
```

سرایت به گرهٔ وابسته (وزن یال `w` بین ۰٫۲ و ۰٫۶):

```
M_linked_new = M_linked_old × (1 − 0.25 × w)
```

## لایهٔ ۱ — بازنشانی مستقیم و کارت دام

- فاصلهٔ کارتِ سؤال به ۱ روز برمی‌گردد.
- سهولت ۰٫۲ کم می‌شود (کف ۱٫۳).
- اگر سؤال `trap_note` داشته باشد، یک‌بار برای همیشه کارت دام ساخته می‌شود (dedup با بررسی وجود کارت قبلی).
- پاسخ درست: فاصلهٔ جدید `round(فاصلهٔ قبلی × ease)` و سهولت ۰٫۰۵ رشد می‌کند (سقف ۲٫۸).

## لایهٔ ۲ — شوک فصل و هم‌خانواده‌ها

شرط فعال‌شدن: پاسخ غلط **و** تسلط جدید زیر ۶۰.

- همهٔ کارت‌های سؤالِ همان گره که سررسیدشان هنوز نرسیده و خودِ کارتِ غلط‌زده نیستند: `I_new = max(1, floor(I_old × 0.5))`
- کارتِ خودِ سؤال دوباره نصف نمی‌شود؛ کارت سررسیدشده (که از قبل در صف امروز است) جلو نمی‌افتد.
- فاصلهٔ اصلی هر کارت فقط بار اول در `previous_interval_days` ذخیره می‌شود تا شوک‌های تکراری آن را بازنویسی نکنند.
- تعداد کارت‌های جلوافتاده به `rippleCapacity` محدود است؛ مازاد گزارش می‌شود (`deferred`) ولی اجرا نمی‌شود — خطا نباید برنامهٔ فردا را منفجر کند.

## ترمیم و تأیید ترمیم (حلقهٔ بستن)

- کارتی که با موج خطا جلو افتاده، `is_repair = true` می‌گیرد.
- اگر کاربر آن را درست جواب دهد، فاصلهٔ اصلی‌اش از `previous_interval_days` بازمی‌گردد (نه رشد تازه) — یعنی «تسلط قبلی شانسی نبود» تأیید شد.
- اگر دوباره غلط بزند، لایه‌ها از نو اعمال می‌شوند.

## لایهٔ ۳ — بازگشت به پیش‌نیاز

برای هر یال `prerequisite` از مبحث خطادار:

1. تسلط پیش‌نیاز با فرمول سرایت کم می‌شود.
2. یک اقدام ترمیم (`schedule_repair`) با شناسهٔ گره هدف ثبت می‌شود تا کارتی از آن مبحث به برنامهٔ فردا برود (در ظرفیت باقی‌مانده).

## لایهٔ ۴ — پل بین‌درسی

برای هر یال `cross_course` از مبحث خطادار — **فقط اگر گرایش گرهٔ هدف برای کاربر فعال باشد** (کاربر تکنولوژی نباید به مبحث اختصاصی بازرگانی سرایت ببیند).

## مرزهای موج (مقاوم در برابر انفجار)

- سرایت فقط یک پرش است (یال‌های مستقیم از مبحث خطادار)؛ به‌صورت عمدی بازگشتی نیست تا گراف چرخه‌ای کل نقشه را جریمه نکند.
- پاسخ درست هیچ موجی ایجاد نمی‌کند؛ فقط رشد می‌دهد.
- همهٔ اعداد با `round1` گرد می‌شوند تا رفتار قطعی و قابل تست بماند.

## صف روزانه

`buildDailyQueue` کارت‌های سررسیدشده را به ترتیب سررسید برمی‌گرداند و فقط کارت‌های گرایش‌های فعال کاربر (هستهٔ مشترک همیشه) را می‌بیند. اگر صف پر نشود، worker برای سؤال‌های دیده‌نشدهٔ همان گرایش‌ها کارت تازه می‌سازد.
