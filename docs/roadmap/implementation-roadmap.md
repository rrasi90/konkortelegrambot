# طرح اجرایی و مراحل

> بنچمارک ویژگی‌ها با محصول الگوی کاربر (واژه‌راه) و ادغام آن‌ها در فازها: [feature-benchmark-vajerah](../product/feature-benchmark-vajerah.md)

## فاز ۰ — اسکلت و مشخصات (انجام‌شده)

- [x] مخزن، پوشه‌بندی، CI (typecheck + تست واحد + تست یکپارچگی دیتابیس)
- [x] قراردادهای مشترک (`packages/contracts`)
- [x] موتور خالص با موج ۴ لایه + ۲۸ تست واحد
- [x] اسکیمای کامل دیتابیس + بذر نمایشی + تست‌های یکپارچگی
- [x] API روی Cloudflare Workers + مینی‌اپ فارسی RTL

## فاز ۱ — بستن حلقهٔ یادگیری (انجام‌شده در سطح دمو)

- [x] ورود (تلگرام/دمو)، انتخاب گرایش، صف امروز
- [x] ثبت پاسخ با idempotency و گزارش موج + پیام منتور
- [x] نقشهٔ مسیر با تسلط زنده
- [x] QA مرورگری حلقهٔ کامل (DOM-verified) و بررسی موبایل ۳۷۵px

## فاز ۲ — سخت‌کردن پایدارسازی (بعدی)

- [ ] **تراکنش اتمی واقعی:** انتقال «رویداد + تسلط + کارت‌ها» به یک Postgres function/RPC تا خرابی شبکه در وسط نوشتن وضعیت را خراب نکند.
- [ ] صف واقعی `daily_plan`: سقف بار روزانه از جدول خوانده شود و اقدامات ترمیمِ به‌تعویق‌افتاده در روزهای بعد برنامه‌ریزی شوند.
- [ ] کارت دام در صف امروز به‌صورت کارت مستقل (فعلاً نکتهٔ دام در بازخورد نمایش داده می‌شود).
- [ ] پاک‌سازی کارت‌های سررسید محافظه‌کارانه (تعریف policy برای کارت‌های بی‌پاسخ طولانی).

## فاز ۳ — محتوای واقعی

- [ ] دریافت و پاک‌سازی سؤالات ۱۱ سال اخیر دکتری مدیریت (هر دو گرایش)
- [ ] نگاشت هر سؤال به گرهٔ دانش + یال‌ها (بازبینی انسانی؛ AI فقط پیش‌نویس)
- [ ] اعتبارسنجی کلید و توضیح‌ها؛ قرنطینهٔ سؤالات مشکوک
- [ ] ارتقای `verification_status` از `unverified` به `verified`
- [ ] سنجش با سؤال دیده‌نشده (بانک قرنطینه) به‌عنوان معیار نهایی تسلط

## فاز ۴ — ربات تلگرام و یادآور

- [ ] ربات همراه: یادآور شبانه، گزارش روزانهٔ پیشرفت
- [ ] اتصال Mini App به ربات (دکمهٔ منو)

## فاز ۵ — یادگیری موتور

- [ ] کالیبراسیون پارامترها با دادهٔ واقعی (به‌جای مقادیر پیش‌فرض طرح اولیه)
- [ ] تشخیص «دام تستی» از «ضعف مفهومی»: اگر کاربر توضیح را می‌فهمد ولی دوباره غلط می‌زند، علت متفاوت است
- [ ] مدل پیش‌بینی احتمال موفقیت (جایگزین عدد تسلط صرفاً تجربی)

## تعریف «تکمیل» برای هر فاز

فاز «تکمیل‌شده» یعنی: تست‌های CI سبز، حلقهٔ کاربر بدون خطا طی شود، و محدودیت‌های باقی‌مانده در `docs/status/implementation-status.md` صادقانه ثبت شده باشند.
