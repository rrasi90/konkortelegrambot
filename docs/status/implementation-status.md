# وضعیت پیاده‌سازی

به‌روزرسانی: فاز اسکلت + حلقهٔ دمو (فاز ۰ و ۱). این سند مرز «چه چیزی واقعاً کار می‌کند» را صادقانه مشخص می‌کند.

## چه چیزی کار می‌کند (تست‌شده)

| بخش | شواهد |
|---|---|
| موتور موج ۴ لایه | ۲۸ تست واحد سبز (فرمول‌ها، شوک هم‌خانواده، dedup کارت دام، ظرفیت موج، ترمیم، فیلتر گرایش) |
| ثبت پاسخ idempotent | تست یکپارچگی API: تلاش تکراری `replay: true` |
| حلقهٔ کامل مینی‌اپ | QA مرورگری: ورود دمو ← انتخاب گرایش ← پاسخ غلط ← گزارش موج با سرایت پیش‌نیاز (sm.rbv ۵۰→۳۸، sm.value_chain ۵۰→۴۴) ← نقشهٔ مسیر |
| نشست و احراز هویت | توکن امضاشده، initData تلگرام (پیاده‌سازی HMAC)، رد توکن جعلی (تست‌شده) |
| دیتابیس | مهاجرت + بذر + ۷ تست یکپارچگی (idempotency، بازهٔ وزن، تسلط، RLS policy) — در CI با PostgreSQL 16 واقعی |
| CI | GitHub Actions: typecheck + تست واحد/یکپارچگی + اعتبارسنجی محتوا + جاب دیتابیس |
| موبایل | ۳۷۵px بدون سرریز افقی (بررسی برنامه‌ای) |

## چه چیزی ساختگی است (صادقانه)

- **کل محتوای آموزشی** دمو است: ۱۳ گره، ۱۰ یال، ۱۴ سؤال فارسی ساختگی با برچسب `demo`. بانک ۱۱ سال اخیر **وارد نشده**.
- **نقشهٔ درسی** (`docs/curriculum/curriculum-map.md`) از طرح اولیه است و با سرفصل رسمی تطبیق داده نشده.
- **فرمول‌های تسلط** از طرح اولیه آمده و کالیبره نشده‌اند.

## محدودیت‌های شناخته‌شده

1. **پایدارسازی چندمرحله‌ای:** ثبت رویداد + تسلط + کارت‌ها سه فراخوانی جداست؛ قطع وسط کار می‌تواند وضعیت را ناسازگار کند. راه‌حل (RPC اتمیک) در نقشهٔ راه فاز ۲.
2. **صف daily_plan خوانده نمی‌شود:** ظرفیت روزانه در `EngineConfig` است نه در جدول؛ اقدامات به‌تعویق‌افتاده ذخیره نمی‌شوند.
3. **QA بصری حالت‌دار محدود:** اسکرین‌شات‌های محیط پیش‌نمایش صفحهٔ تازهٔ URL را رندر می‌کنند؛ صفحات پس از ورود فقط در سطح DOM تأیید شدند (متن منتور، نوارهای تسلط، علامت گزینه‌ها). رندر بصری صفحهٔ ورود (همان سیستم استایل) تأیید شد.
4. **ماندگاری نشست در محیط QA:** iframe پیش‌نمایش localStorage را مسدود می‌کند؛ رفرش-ماندگاری در اپ واقعی (که از localStorage استفاده می‌کند) در آن محیط قابل آزمون نبود.
5. **کارت دام در صف:** فعلاً نکتهٔ دام در بازخورد سؤال نمایش داده می‌شود؛ کارت مستقل دام در صف امروز هنوز در جریان صف پشتیبانی نمی‌شود.
6. **استقرار ابری انجام نشده:** کد آماده wrangler/Supabase است ولی اعتبارنامه‌های استقرار (توکن Cloudflare، پروژهٔ Supabase) متصل نیستند.

## اجرای محلی

```bash
npm install
npm run typecheck && npm test          # تست‌ها
npx tsx scripts/dev-server.mjs          # http://localhost:8787 (مینی‌اپ + API با بستهٔ دمو)
npm run db:test                        # نیازمند DATABASE_URL
```
