# وضعیت پیاده‌سازی و تطابق سامانه (Audit & Implementation Status)

به‌روزرسانی: فاز یکپارچه‌سازی موتور، امنیت مرز اعتماد، گراف دانش دکتری مدیریت و آزمون‌های سنجش.

## چه چیزی واقعاً کار می‌کند و راستی‌آزمایی شده است

| بخش | شواهد و آزمون‌ها | وضعیت |
|---|---|---|
| **موتور یادگیری تطبیقی (Ripple Engine)** | ۲۱ تست واحد در `@ael/engine`: فرمول‌های شوک هم‌خانواده، ظرفیت موج ۴لایه، فیلتر گرایش، ترمیم پیش‌نیاز | ✓ سبز (Vitest) |
| **محاسبات اولویت صف (Priority Calculations)** | ۷ تست واحد جدید در `packages/utils`: تصحیح فرمول بازگشتی سررسید، محاسبهٔ معکوس تسلط (تسلط کمتر = فوریت بیشتر)، مقادیر آزمون | ✓ سبز (Vitest) |
| **امنیت کلاینت و API ورکر** | ۱۰ تست یکپارچگی در `apps/worker`: عدم افشای پاسخ (`correctOption`، `explanation` و `trapNote` تا قبل از ثبت پاسخ هرگز به کلاینت نمی‌رسد)، ارسال با `PublicQuestion` DTO، دریافت پاسخ و بازخورد پس از سابمیت | ✓ سبز (Vitest) |
| **دیتابیس PostgreSQL و مهاجرت‌ها** | ۶ فایل مهاجرت کامل (`0001_init` تا `0006_learner_and_security`) به همراه بذر `0001_demo_pack` و ۸ تست یکپارچگی روی PostgreSQL واقعی توکار | ✓ سبز (Embedded PG) |
| **ایزولاسیون امنیتی داده (RLS)** | تست تعویض نقش به `authenticated` با `set ael.uid`؛ رکوردهای کاربر فقط برای خود او قابل خواندن است و برای سایر کاربران کاملاً مسدود است | ✓ سبز (Embedded PG) |
| **اعتبارسنجی بسته‌های محتوایی** | تست `scripts/validate-content.mjs`: هر دو بستهٔ دمو (`demo-pack-phd-management`) و بستهٔ واقعی دکتری مدیریت (`phd-management-business-v1`) اعتبارسنجی شدند | ✓ سبز (0 خطا) |
| **مینی‌اپ فارسی و راست‌چین** | رابط کاربری مدرن با تم تاریک/روشن، دریافت صف، سابمیت پاسخ، نمایش امن بازخورد و یادداشت دام پس از پاسخ، کوییز شبانه و سیستم سکه و زنجیره | ✓ تأیید شده |

## وضعیت محتوای دکتری مدیریت (گزارش ممیزی شفاف)

1. **بسته‌های محتوای دیتابیس / موتور:**
   - **بستهٔ دمو (`demo-pack-phd-management`):** ۱۳ گره، ۱۰ یال، ۱۴ سؤال دمو (دست‌نخورده و تفکیک‌شده با شناسه و فلگ مجزا).
   - **بستهٔ واقعی دکتری مدیریت (`phd-management-business-v1`):** ۱۸ گره، ۱۴ یال، ۲۱ سؤال واقعی استخراج‌شده از آزمون‌های دکتری مدیریت ۱۴۰۲ تا ۱۴۰۴ (کد ۲۱۶۴)، نگاشت‌شده به گره‌های دانش، سطوح بلوم و یادداشت‌های دام طراح.

2. **کتاب‌های مرجع (۹ کتاب اصلی):**
   - همهٔ ۹ مرجع در `content/markdown/books/` دارای پوشه، شناسنامه و متادیتای کتاب‌شناختی (`metadata.md`)، سرفصل کامل (`table-of-contents.md`) و خلاصهٔ فصول به تفکیک هستند.
   - وضعیت حقوقی همهٔ کتاب‌های تجاری به‌درستی `licensed` ثبت شده و خلاصه‌ها به‌صورت تألیف مستقل یادگیری تدوین شده‌اند تا مالکیت فکری ناشران نقض نشود.

3. **دفترچه‌های آزمون ۱۰ سال اخیر (۱۳۹۵ تا ۱۴۰۴):**
   - دفترچه‌ها و کلیدهای رسمی در `content/research/annual-coverage.json` و `annual-coverage.csv` فهرست شده‌اند.
   - تمایز شفاف: سؤالات دفترچه کاغذی سنجش (۸۰ سؤال تخصصی در هر دوره) در برابر سؤالات استخراج و اعتبارسنجی‌شده در قالب ماشینی JSON (۲۱ سؤال در نسخهٔ v1). سال ۱۴۰۴ به‌عنوان جامعهٔ ارزیابی نهایی (Holdout) قرنطینه است.

## فرمان‌های راستی‌آزمایی محلی

```bash
# ۱. تایپ‌چک کل پروژه
npm run typecheck

# ۲. اجرای تمام ۳۸ تست واحد (موتور، ورکر، محاسبات اولویت)
npm test

# ۳. اعتبارسنجی بسته‌های محتوا
npm run validate:content
node scripts/validate-content.mjs content/knowledge/exam-packs/phd-management-business-v1.json

# ۴. اجرای کامل تست‌های مهاجرت، بذر و RLS روی PostgreSQL واقعی توکار
node scripts/db-test-embedded.mjs
```
