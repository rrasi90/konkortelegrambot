بازاریابیفصل ۳ · STPسؤال ۷ از ۲۰
تست ۱۴۰۳سؤالات ۱۹۱ تا ۲۰۵بازیابی از دفترچه

کدام مورد از مهم‌ترین الزامات پیش از اجرای آمیختهٔ بازاریابی در یک بازار جدید است؟

✓ پاسخ صحیح — تسلط این مبحث به‌روز شد

قبل از تصمیم دربارهٔ 4P باید بدانیم برای چه کسی (بخش‌بندی)، کدام بخش را هدف می‌گیریم و چه جایگاهی می‌سازیم. بدون STP، آمیختهٔ بازاریابی هدف ندارد.

دام طراح: گزینهٔ «بودجهٔ تبلیغات» کمی محسوس‌تر است اما بدون STP فقط اتلاف منابع است.
