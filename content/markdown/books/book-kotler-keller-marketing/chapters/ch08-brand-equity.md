# فصل ۸: دارایی ویژه برند و مدل هرم رزونانس (CBBE Keller)

## ۱. تعریف ارزش ویژه برند مبتنی بر مشتری
- اثر متمایزی که دانش برند بر پاسخ مصرف‌کننده نسبت به بازاریابی آن برند دارد.

## ۲. هرم چهارمرحله‌ای و شش‌بلوکی کلر
```
        ┌───────────────────────┐
        │  هم‌آوایی برند (Resonance) │  <-- قله: پیوند عاطفی، وفاداری، جامعه، مشارکت
        └───────────┬───────────┘
     ┌──────────────┴──────────────┐
     │ قضاوت‌ها (Judgments) │ احساسات (Feelings) │ <-- مرحله ۳: واکنش مشتری
     └──────────────┬──────────────┘
     ┌──────────────┴──────────────┐
     │ عملکرد (Performance) │ تصویر (Imagery)    │ <-- مرحله ۲: معنای برند
     └──────────────┬──────────────┘
        ┌───────────────────────┐
        │   برجستگی برند (Salience)    │  <-- پایه: هویت و آگاهی از برند
        └───────────────────────┘
```

## ۳. برندسازی مشترک (Co-Branding)
- ترکیب دو برند شناخته‌شده برای خلق یک ارزش متمایز، کاهش ریسک خرید مشتری در ورود به بازار جدید و تقسیم هزینه‌های توسعه بازار.
